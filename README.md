# Observatório de Políticas Públicas — Skill

Repositório dedicado ao desenvolvimento colaborativo da Skill de investigação de políticas públicas brasileiras.

## Objetivo
Investigar promessas, decisões, execução e resultados usando documentos originais, dados públicos, contexto histórico e limites explícitos de atribuição.

## Estado do projeto
A versão distribuída pelo site está em `https://taleshenrique.dev/politicas-publicas/skill.zip`. A importação dos arquivos originais para este repositório ainda está pendente; não trate este README como substituto do pacote da Skill.

## Colabore
Abra uma [issue](../../issues) para sugerir novas fontes, correções e melhorias. Faça um [fork](../../fork), crie uma branch com sua proposta e envie uma pull request para contribuir com o projeto principal.

## Princípios
- Priorizar fontes primárias e registrar URLs e datas.
- Comparar indicadores com atenção à metodologia e à série histórica.
- Distinguir fatos, hipóteses, correlação e causalidade.
- Evitar recomendações eleitorais e dados inventados.

A licença de redistribuição ainda precisa ser definida antes de publicar versões derivadas.
